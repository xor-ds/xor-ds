Data Scientist и Канбан-коуч с 15-летним опытом в банковском финтехе. Специализация на инвестиционных продуктах и корпоративных сервисах. 

**Экспертиза**
- Запуск digital-продуктов (первый мобильный банк для бизнеса в России)
- Data-driven управление на основе глубокой аналитики метрик
- Разработка ML-решений для инвестиций и банковских процессов

**Стек:** Python, PyTorch, LSTM/GRU, LightGBM, CatBoost, Scikit-learn, Java
