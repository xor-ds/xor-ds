## Обо мне

Data Scientist и Канбан-коуч с экспертизой в банковском финтехе

Более 15 лет опыта в банковском секторе, где прошел путь от управления ИТ-проектами до запуска цифровых продуктов. Специализируюсь на применении data-подходов в управлении продуктами, ИТ-процессами инвестиционного и корпоративного бизнеса.

### Ключевая экспертиза

**🏦 Инвестиционные и корпоративные банковские продукты**
- Глубокое понимание продуктов инвестиционного бизнеса: торговые платформы, брокерское обслуживание, риск-менеджмент
- Экспертиза в корпоративных продуктах: cash management, факторинг, валютные операции, кредитный конвейер
- Опыт запуска и развития digital-каналов для корпоративных клиентов, включая первый в России мобильный банк для бизнеса

**📊 Data-Driven управление процессами**
- Профессиональный Канбан-тренер. Прошел аккредитацию в качестве Accredited Kanban Trainer (AKT) в Kanban University
- Специализация на глубоком анализе процессных метрик с акцентом на их статистическую значимость
- Разработка инструментов для аналитики данных и автоматизации оценки метрик

**🤖 Прикладной Data Science**
- Разработка и внедрение ML-моделей для инвестиционных и банковских продуктов
- Опыт работы с NLP, RAG-архитектурами, временными рядами
- Стек: Python, PyTorch, LSTM/GRU, LightGBM, CatBoost, Scikit-learn, Java
